# Pagination (Page and Per Page)

This package uses page-based pagination for list endpoints.

## Query Style

- `page`
- `per_page`

## Response Meta

- `meta.page`
- `meta.per_page`
- `meta.total`

Cursor-based pagination is deprecated and removed.
